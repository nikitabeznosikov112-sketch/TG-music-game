## Game Bot

Телеграм-бот с играми. Позволяет пользователям играть в различные мини игры сохраняя их статистику. Имеет панель администрирования.

## Установка и запуск

### Через Docker

1. Установи [Docker](https://docs.docker.com/get-docker/) и Docker Compose.
2. Создай `.env` по примеру `.env.example` и заполни его.
3. Запусти проект одной командой:
```bash
docker compose up --build
```
- Панель администратора будет доступна по адресу http://127.0.0.1:8001/admin
### Локально (без докера)
1. Установи зависимости
```bash
pip install -r requirements.txt
```
2. Создай `.env` по `.env.example`
3. Создай базу данных
4. Примени миграции (для первого запуска):
```bash
alembic upgrade head
```
5. Запусти `BOTLogic.py` для запуска бота
6. Для панели администрирования запусти 
```bash
uvicorn admin:app --host 127.0.0.1 --port 8001
```
- - Панель администратора будет доступна по адресу http://127.0.0.1:8001/admin

## Функции

### У пользователя:
- Игра Угадай какая песня популярнее (с выбором жанров)
- Игра Угадай породу собаки
- Игра Угадай из какого фильма кадра
- Доступ к собственному счету
- Просмотр рейтинга среди игроков

### У администратора
- Просмотр всех пользователей, их айди с Телеграма, айди в базе данных и счетом
- Удаление пользователей из базы данных
- Сброс очков пользователя
